# 📊 Telemetry Collection System

Эмулятор системы сбора и обработки телеметрии на Python. Система собирает данные из 4 источников, валидирует их, сохраняет в базу данных SQLite и ведет журнал предопределенных трендов.

## 🚀 Основные возможности

- **4 источника данных**: Раз в секунду каждый источник генерирует от 100 до 600 объектов (скалярные числа и булевы значения).
- **Валидация**: Строгая проверка типов (`scalar` / `bool`), отсеивание `NaN`, `inf`, `None`, строк и других невалидных значений.
- **Хранение (SQLite)**: Все валидные данные сохраняются в БД. Невалидные — логируются в отдельную таблицу и текстовый файл.
- **20 трендов**: Предопределенный набор объектов (от `trend_00` до `trend_19`), которые дополнительно журналируются.
- **Окно видимости**: Журнал трендов удерживает в оперативной памяти скользящее окно на **3600 элементов**.
- **Без GUI**: Система работает в фоновом режиме через терминал (с корректной обработкой `Ctrl+C`).

## 🛠 Требования

- Python 3.10+ (используется `dataclass(slots=True)`)
- Внешние зависимости **отсутствуют** (используется только стандартная библиотека).
